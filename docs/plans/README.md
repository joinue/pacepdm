# Plans

Forward-looking work, one file per effort. Distinct from [`../decisions/`](../decisions/), which records choices already made and is kept current forever.

A plan is a **dated snapshot**: accurate when written, stale soon after. Trust the counters it tells you to run over the numbers printed in it. When a plan is finished, delete it — the durable part belongs in a decision doc or in `AGENTS.md`, not here.
